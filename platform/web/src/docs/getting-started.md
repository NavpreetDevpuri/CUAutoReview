# Getting started

CUAutoReview is a local workspace for reviewing saved computer-use task evidence. Use the workspace navigation to move between datasets, runs, trajectories, taxonomy, and activity. Your color-mode choice is saved on this browser.

## Sign in and create a workspace

Create a local account from the sign-in screen. The first account in a new workspace becomes its administrator. Later accounts start with viewer access until an administrator changes their role. Your workspace data and sign-in are managed by the local application.

## A typical review workflow

1. Create a dataset and import saved task records.
2. Select a dataset or its tasks in the run composer.
3. Choose a review workflow and execution preset, then confirm and start the run.
4. Open task trajectories to inspect screenshots and recorded review results.
5. Add feedback or propose taxonomy changes when needed.

Importing a dataset does not start a run or call a model. The run composer shows the workflow prompt separately from the harness/model configuration. Hosted inference can make provider calls, so the run requires explicit budget confirmation before it starts.

## Find help for a task

Use the Help and guides link at the bottom of the workspace navigation. Each guide has a table of contents. Select a heading to jump to that section; the guide stays inside the application route.
